This repo contains only the selected extension sources from the Manga-Scraper-Tool-1 project.

Included extensions:
- Pawchive
- Rule34
- Panda Chaika
- Koofr
- AnimeGG

Each extension folder contains:
- index.min.json
- source.ts

These were extracted from the original `artifacts/api-server/src/sources` folder and kept as source files for custom Tachiyomi-style extension packaging.
